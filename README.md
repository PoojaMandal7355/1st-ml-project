# 🚕 NYC Taxi Trip Duration Prediction

My first end-to-end Machine Learning project using real-world NYC taxi trip data.

## 🎯 Project Goal

The goal of this project is to build a Machine Learning model that can predict the duration of a taxi trip based on information such as pickup location, drop-off location, pickup time, passenger count, and other available features.
